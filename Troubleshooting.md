


For Help Desk and IT Support Specialists, the same IT support scenarios appear frequently. Knowing how to troubleshoot them efficiently is essential for smooth operations.

**How would you troubleshoot a computer that will not turn on?**

Start by checking the power source, cables, and outlet. Look for signs of power, such as lights or fans. Try a different power cable or outlet. If it powers on, but will not book, disconnect the peripherals and check hardware, like RAM.

**A user says their computer is slow. What do you do?**

Ask when the issue started and wheat applications are being used. Check task Manager for high CPU, memory, or disk usage, review startup programs, available disk space, update, and run malware checks if needed. 

**How would you reset a user’s password?**

First, verify the user’s identity following company policy. Reset the password using the appropriate system, such as Active Directory and advise user to change password after login.
